A production-level animated portfolio website built with modern web technologies.

## Features

- 🌙 Dark/Light theme toggle with system preference detection
- ✨ Smooth animations powered by Framer Motion
- 📱 Fully responsive for all screen sizes
- ⚡ Optimized performance with Next.js 14 App Router
- 🔍 SEO-ready with proper metadata and Open Graph tags
- ♿ Accessible with ARIA labels and focus states
- 📧 Contact form with validation and spam protection
- 🎯 Typewriter effect on hero section
- 📊 Skills with animated progress bars
- 🗂️ Filterable project grid

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Forms:** React Hook Form + Zod
- **Icons:** Lucide React

## Getting Started

```bash
git clone https://github.com/aniket9538-coder/MyPortfillo.git
cd MyPortfillo
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
